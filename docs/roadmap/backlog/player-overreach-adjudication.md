# 玩家過強輸入與 GM 控場（合理範圍）

**狀態：** 已排程 **[0.11.0](../0.11.0/INDEX.md)**（`planned`）。本檔為構想備註；**契約以 0.11.0 INDEX＋`docs/overreach.md` 為準**（衝突時以版本文件為準）。出貨後刪本檔與 backlog 列。

**現行：** 玩家每回合自由文字 `player_text` → `POST /api/turn` → GM JSON → Writer 落 KB。無技能檢定、無「行動是否成立」欄。約束靠 prompt + zod 形狀。文字 NSFW 允許（玩家帶向）；未成年人 **硬禁**，與本項「過強但合法」不是同一類。

本檔**不**覆寫 0.4.0／0.8.0／0.10.0 契約。例證皆虛構；勿把 live `kb/worlds` 對白寫進日後 INDEX。0.9.0：若有待判決 UI，**取代**對局 busy，不要兩套疊加。

與既有項分工：本項管 **過強行動裁決、故事／GM 分頻道、`player-memory/`**。不取代 Writer／NPC 記憶。不引入完整戰鬥或技能表。

---

## 產品句（構想）

自由文字仍是故事輸入形態。玩家 **不能** 用一段「我已殺死全場／我其實是神／世界突然改設定」就把故事扭成外掛通關。超過相對 **本場 canon** 的合理範圍時，控場發生在 **故事頻道之外** 的 GM 對話；未過線則與今日相同，零額外點擊。

## 已收斂形狀（討論結論，排程時可再推翻）

### 兩頻道

- **故事：** 現有對局 log／輸入。過線待決時顯示狀態 **「行為待判決」**（輸入列狀態，**不是** `#log` 敘事氣泡），故事輸入 disable。
- **GM：** 獨立 conversation channel（玩家與 GM 直接談規則／設定）。預設收成小 icon，不佔版面；用戶可手動開收。僅當深層裁決仍認為要談時才自動展開。結案後再收起（紀錄可留在該側，不必當第二條主劇情）。
- 裁決、勸說、選項 **不** 寫進故事 NPC 對白，也 **不** 進對局 pi session／Writer，直到終態放行或切分。

### 兩層裁決

```text
player_text
    → 輕量先裁（快；明顯 OK 則 PASS）
        → 直接故事 GM（現行一拍）
    → 可疑則 meta GM 深審（UI 仍收起）
        → 其實沒問題 → PASS，故事 GM，玩家無感
        → 仍過線 → 展開 GM 側欄
```

輕量層寧可誤報（由深層收回 PASS），但 **聲稱已成功／已改世界** 應 escalate，即使句子很短。漏抓外掛才是真正風險。

深層／側欄 meta 每一則須 **機器可讀終態**（玩家只見聊天），例如：`talk`／`pass_original`／`split`／`revise`。沒有這欄則無法解鎖故事。

### 側欄裡用文字講選項（不強制按鈕）

GM 用簡單句子說明問題，並列出：

1. **給理由說服** 為何允許（例如補充「我真的有這能力」）→ 改該存檔 **玩家設定／事實**；GM 仍可拒。可多輪，隨玩家喜歡談。
2. **切分：** 合理段嘗試／成立，過線段＝想這麼做但做不到；然後故事 GM 續寫。
3. **重輸** 本則故事輸入。

結案：

- **(1) 接受** → 程式寫入 `player-memory/` → **原** `player_text` 進故事 GM（玩家不必重打）→ 解鎖故事 → 側欄收起。
- **(2)** → 故事 GM 帶切分約束；`events[]` 只准成立段 → 解鎖 → 收起。
- **(3)** → 原句丟棄，不解進故事 session → 解鎖故事輸入 → 收起。
- 深層第一次就 PASS：不開側欄。

待決期間不得並行第二則故事 turn；回主頁／刪世界須清 pending。Writer／`gm_note`／entities **終態前不落盤**。

### 硬拒（不走側欄談判）

契約攻擊（忽略指令、規定 events）與未成年人：整段拒，不給 (1)(2) 把違禁寫成嘗試。傾向不消耗世界狀態、不進對局 session。

## `player-memory/`（已收斂：做，但是參考用）

該 uuid 下獨立樹，例如 `kb/worlds/{uuid}/player-memory/`（第一版可極瘦 `current.json` body）。**不要** 把玩家塞進 `npc-memory/`，**不要** 套 L2 `psyche.json` 六欄（那是給被演的 NPC）。

寫什麼：

- **要：** 已承認的能力／破例（選 (1) 談成的）、世界已看見的事實（可選：Writer 從 `events[]` 機械摘「做過什麼」）。
- **不要（第一版）：** 自動 distill 人格、人生目標、喜好——會與玩家此刻想演的人設衝突。

誰讀：故事 GM、輕量／深層裁決、meta 側欄；另欄（如 `player_memory`），**不** 進對玩家故事 HTTP 氣泡。

優先序（prompt 硬規則）：**本回合 `player_text`** ＞ 玩家檔事實／已接受 canon ＞ 世界 KB。記憶避免健忘與重複審能力；**禁止** 用記憶否決這拍人格；禁止代寫玩家內心當既定性格。玩家改口視為角色在變或在演，不是檔案錯誤——去改已落地世界事實才走控場。

(1) 接受後必須寫檔，否則下一拍同類行動會再跳頻道。Mock：破例寫入後輕量先裁應 PASS。

刪世界＝連同該 uuid 的 `player-memory/`；回主頁不清。

## 何謂「合理範圍」（類別，非數值檢定）

**傾向過線：** 立刻改寫世界 canon；無代價絕對成功（且本場未承認該能力）；跳過單場景場面約束；契約攻擊。

**傾向仍合理：** 困難嘗試（說謊、偷、打、勸、逃、帶向成人向）；聲稱強大但未要求世界立刻承認結果；本場 default／custom canon 或 **`player-memory/` 已承認** 的能力。合理相對 **本場世界**，不是地球物理。

過線指能力／canon，**不** 審查合法成人向。

## 舊三路徑（對照）

討論初期的整段拒／自動切分／預覽確認卡，收斂後對應：硬拒＝路徑 1；側欄選 (2)＝玩家同意後的切分（非自動落地）；(3)＝重輸；(1) 為新增的 canon 談判。不再做故事氣泡裡的確認卡。

## 非目標（本項）

- 完整 D&D 技能表、戰鬥 round、數值 HP。
- 審查合法成人向；用按鈕取代自由文字當預設玩法。
- 終態前改 `gm_note`／entities／對局 session。
- 玩家 L2 psyche／自動性格摘要／玩家記憶編輯器產品 UI（第一版）。
- 華麗多頻道 IM；側欄第一版是可收合的第二輸入，不是 Discord。
