# GM 控場：短期目標＋中期骨架（雙視野）

**狀態：** backlog 構想，**尚未排入任何 `docs/roadmap/X.Y.Z/`。** 不是承諾範圍；方向未定。  
**閘門：** 排程與實作前必須 **interview Eric** 收斂做法。未談定前不要當 HANDOFF、不要改 `gm_note` 契約、不要寫死 default 北路情節。

本檔**不**覆寫現行回合契約。例證用 seed／canon 已公開的鉤子方向，勿把 live `kb/worlds/` 對白寫進日後 INDEX。

與 [玩家過強輸入與 GM 控場](./player-overreach-adjudication.md) 分工：那項管 **玩家宣稱是否成立**；本項管 **GM 自己有沒有中期情節骨架**，以及骨架與玩家即興走歪時如何接得上。兩者都叫「控場」，不是同一產品問題。

---

## 產品句（構想，未定案）

GM 不應只靠 **一個很短期的目標** 然後整場即興。應同時有：

1. **短期目標** — 接近現行 `gm_note`／本場未決鉤子：這一兩拍要推什麼、誰在場、眼前張力。
2. **中期骨架** — 預先預備、可隨機應變的大方向：這條線往哪裡鋪、大約會碰到什麼布局／事件／對手，而不是把下一幕細節寫死。

Default 現況的張力（虛構摘要，對齊 seed）：酒館線索指向「北面／燈手」，但 **北面有什麼、將鋪什麼事件、線索落到哪、要面對什麼強敵或鬼怪**，當下並未寫死，幾乎全靠模型當下即興。構想是：中期柱架可以定下（例如守燈人失蹤、線索導向某處、那裡有某種對抗），短期仍像現在一樣即興接玩家這一拍。

## 問題（現行缺口）

| 層 | 現在 | 缺口 |
|----|------|------|
| 對局 GM | 每回合吃 `gm_note`（整份覆寫）＋ scene＋記憶切片 | `gm_note` 實務上是 **極短視野**；沒有獨立、可跨多回合的中期柱架欄位或檔 |
| Default canon | `prompts/gm-default.md`＋seed 一條北路鉤子 | 鉤子停在「去北面」等級；布局／事件序列／對手未預備 |
| Compact | 保留 GM note／在場誰／未決鉤子／本場目標 | 封完仍只有短期；沒有「北線骨架」可帶回 |
| 玩家自由 | 自由文字、單場景 POC | 即興很容易走歪；若骨架寫太死，接不上會變成硬拉或斷線 |

失敗模式（皆可能，故不要未談就實作）：

- **只有即興：** 北面每次都是不同故事，線索不累積，compact 後更散。
- **寫太死：** 玩家不跟北路、改去追酒館裡另一件事，骨架接不上，GM 硬拽回「你必須去北面」破壞自由冒險。
- **只靠更長 prompt：** 模型仍只盯眼前一句；沒有機械欄位／Writer 落盤，中期目標會被 `gm_note` 整份覆寫沖掉。

## 未解張力（interview 核心）

Eric 已點出、本檔不假裝已解：

> 中期柱架想定（布局、事件、線索落點、對手），但又怕寫太死；玩家即興一歪就接不上。

Interview 至少要談清：

1. **骨架粒度：** 主題／禁忌／「可能事件池」，還是半線性節點（A→B→C）？
2. **偏離怎麼辦：** 骨架作廢並生成新中期、骨架擱置等玩家繞回、還是用軟鉤子把現況接回原柱（不強迫地理）？
3. **誰寫骨架：** 作者預寫在 default／custom canon、setup 生成一次、還是對局中 GM 偶爾更新（誰准覆寫）？
4. **落盤：** 獨立檔（例如 runtime `plot.json`）vs 只活在 `gm_note` 分段 vs 只活在 prompt。覆寫規則要避免短期把中期洗掉。
5. **Custom：** 自訂引子有沒有中期？沒有是否 setup 時生成一版可改的骨架？
6. **POC 邊界：** 本產品不做多地點／任務系統／戰鬥。中期「去北面面對鬼怪」不可順便做成地圖與任務日誌，除非 interview 明確擴大 scope。

## 構想傾向（僅討論起點，可推翻）

- 雙視野同時存在，不是用中期取代短期。
- 中期偏 **預備＋隨機應變**，不是攻略路線圖。
- 實作前 **必須先 interview**；本項允許長期停在 backlog。
