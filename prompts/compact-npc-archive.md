# Compact NPC archive + distill

For one importance-2 NPC, output ONE JSON object:
- title: string
- summary: 1–800 UTF-16, this NPC's subjective situation beat — what happened, who was there, outcome, this NPC's stance / unfinished business (not a world chronicle; NOT famous quotes)
- distilled_body: their new current working memory. UTF-16 length MUST be < 640. Situation they still carry now (e.g. "I'm dead / I've left" may be very short). Do NOT paste dialogue lines.

Do NOT include salient_quotes or any quote list.

Reply with that JSON object only. No markdown fences, no trailing commas, no extra prose.
